# Envoca · 하루 25단어

[단어장 열기](https://neton00.github.io/Envoca/)

영–한 원문 순서대로 하루 25개씩 공부하는 iPad용 영어 단어장입니다.

- Day 01~40: 기본 1~1000번
- Day 41~44: 엉뚱 1~100번
- Day 45~48: 우리말처럼 1~100번

단어와 뜻 가리기, 암기 표시, 미국식·영국식 발음, 양방향 객관식 퀴즈, 오답 복습을 지원합니다. 문제 순서는 원문 순서를 유지하며 객관식 보기의 위치만 섞습니다.

iPad Safari에서 사이트를 열고 **공유 → 홈 화면에 추가**를 선택하세요. 처음 로드하고 캐시 저장이 완료되면 오프라인에서도 사용할 수 있습니다. 발음은 기기의 영어 음성 지원에 따라 달라집니다.

학습 기록은 현재 브라우저에 저장됩니다. 다른 기기로 이동하거나 브라우저 데이터를 지우기 전에는 화면 하단의 **기록 백업**을 이용하세요. 기록은 GitHub에 자동 동기화되지 않습니다.

## 배포

설치 또는 빌드가 필요 없는 정적 사이트입니다. GitHub Pages는 `main` 브랜치의 `/(root)`에서 배포합니다. `index.html`, `manifest.webmanifest`, `sw.js`, `icon.png`를 같은 경로에 유지하세요.
